# PawPal+ care guide

This folder is the knowledge base the PawPal+ planning agent searches before it
creates tasks. Each `##` section is one retrievable passage, so keep sections
short, self-contained, and concrete (minutes, how often, how important).

This is general guidance for planning a routine, not veterinary advice. Anything
involving illness, medication doses or behaviour changes should follow what the
owner's vet has said.
